`main.ts` writes a single original excuse line (120 characters) to `/output/entry.txt`:

> Sorry — I outsourced your deadline to a subagent, who outsourced it to another subagent, who is still reading the brief.

The joke is the delegation chain: the agent missed the deadline by handing it down a ladder of subagents, each further from the actual work, until the last one has not even read the brief yet — an excuse only an agent could give.
